# PKG-AMBILIGHT-02 历史行为与失败复现

沿用01两个实际发布及冻结工作区，30项Node测试分别验证频率/暂停/重复start-stop和
历史异常路径。对id=0、销毁后逃逸start、取色异常卡住旧handle、空context/零尺寸、
取色中stop/destroy重入、设置样式失败和已销毁host晚注册建立可重跑断言。

浏览器使用原生video、Canvas和RAF；三个核心（实际npm5.1.7、npm5.4.0及候选）、
三插件实现、三引擎验证9格取色、暂停/停止保留颜色、切源和destroy(false)残留视图。
127.0.0.1页面加载localhost同端口视频构成真实跨origin；手动start捕获原生SecurityError，
切回同源且媒体播放后仍复现同一错误，证明历史Canvas污染持续存在。没有拦截网络或
模拟像素/原生异常；主动catch用于避免将预期旧缺陷变成浏览器未处理错误。

Node模拟器的零尺寸被允许，只证明缺少尺寸保护，不声称浏览器一定抛某种异常；真实
浏览器结果与源文件/样本/引擎/Core版本由附件保存。默认全局CI仍执行全部必要门槛。
专项、三引擎和完整CI结果见 [验证记录](../baselines/ambilight-behavior-validation.json)。

这些断言固定的是历史问题，03需另加候选应当修复的断言，不能改旧快照让缺陷消失。
下一步拆分视图、取色和RAF/销毁归属，保留正常stop/配置/样式/返回行为；类型和最终
分发仍归04/06，实际设备与代理能力归05。无生产源码变更、推送或发布。
