## 实现和兼容

冻结关联核心 artplayer 3.5.31 的完整 npm 归档，逐个验证 144 个成员 SHA256、
registry integrity、归档 SHA256 和 manifest。历史 Git 核心版本关联一致，见
[归档](../baselines/thumbnail-core.json)。这是历史关联版本，不是最低支持版本，
也不代表找回了原始 thumbnail 工具的完整归档或声明。浏览器服务新增独立路由，
保留原 published 5.4.0 路由，每次读取先校验归档和 main。

`thumbnail-core.spec.js` 将恢复的 CDN 3.5.31、冻结工作区工具和重构工具的
默认/workspace 策略分别接入核心 3.5.31、5.4.0 和重构核心。原生文件选择、
实际解码、工具生成 PNG、真实鼠标悬停，每组两次生成并重建播放器，检查图片
640×300、12 个样本中心、5 个取格位置、预览像素、URL 更新和销毁。
截图比较上部未被时间提示遮挡的区域，排除圆角，平均 RGB 通道误差上限为 3；
没有隐藏提示或修改产品样式。

旧核心在行边界取上一行最后一格、返回首格时保留上次位置，是已有缺陷；旧结果
明确断言，重构核心必须显示正确格子。核心 5.4.0 初始化会撤销空的前一媒体 URL，
两次初始化精确记录两个空值；所有非空创建/撤销仍精确匹配。

图片有 30px 页脚，应显式传入与生成配置一致的 number/column/width/height；
本组合 scale=1。工具持有图片和媒体 Blob URL，先销毁引用它们的播放器，再生成
下一张或销毁工具；播放器不得撤销外借 URL。包内架构和测试文档同步补充。

## 失败调查和修正

- 初次将另一素材的末格红色预期错误套用到本素材，12 项失败。独立 FFmpeg 在
  1、3、…、23 秒解码确认所有中心蓝色，修正预期并保存原报告。
- 随后 12 项整图比较失败，截图确认时间提示遮挡下部。改比较未遮挡区域，
  没有扩大误差阈值。一次已发布核心空 URL 撤销差异改为按实际代码精确断言。
- 统一 delay=20 时，Firefox 三个恢复版 3.5.31 组合生成黑格：0/4/8 格中心蓝色，
  其余黑色。历史源码只等计时器后 drawImage，不等 seeked。正常组合使用旧版原
  默认 delay=300 后通过；重构工具仍使用 delay=20。保留失败，不声称旧版短延时通过。
- 安装产物首次 17 通过/1 失败：video.error 已设置，排队的 error 事件尚未送达。
  改为在原超时内等待精确一次通知；安装 18 项和源码 WebKit 12 项通过。源码完整
  36 项在这次等待改动之前运行，其测试文件另存哈希；跟进结果单独记录。
- 归档测试纠正错误的 Vitest 导入，使用项目原有 Node 运行器，没有新增依赖。
